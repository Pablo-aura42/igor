# igor 🧮

> Маленький калькулятор с большими амбициями — Python + CustomTkinter.

[🇬🇧 English version](README.md)

Минималистичный настольный калькулятор с 12 цветовыми темами, четырьмя режимами, историей вычислений и сохранением настроек. Написан на Python с использованием CustomTkinter.

## ✨ Возможности

- 🎨 **12 цветовых тем** — Catppuccin (Mocha, Macchiato, Frappé, Latte), Nord, Ayu (Dark, Mirage), Dracula, Tokyo Night, Gruvbox Dark, One Dark, Solarized Dark — с переключением на лету
- 🎛️ **4 режима** — простой, расширенный, финансовый, программирование
- 📜 **История вычислений** — можно кликнуть по записи и вставить результат обратно в дисплей
- 💾 **Сохранение конфига** в `~/.config/igor/config.json` — тема, режим и история переживают перезапуск
- ⌨️ **Горячие клавиши** — цифры, операторы, `Enter`, `Backspace`, `Esc`, `Ctrl+L`, `Ctrl+H`, `Ctrl+Q`
- 🖱️ **Hover-эффекты** — у каждой категории кнопок свой цвет подсветки
- 🧠 **Обработка ошибок** — деление на ноль, корень из отрицательного, логарифм неположительного и т.д. показываются красным «Ошибка»
- 🎯 **Защита от ошибок ввода** — нельзя поставить две точки в одном числе, нельзя оставить ведущий ноль, `Backspace` убирает по одному символу

## 🎛️ Режимы

| Режим | Операции |
|---|---|
| **Простой** | `+ − × ÷ %`, `±`, `⌫`, `C` |
| **Расширенный** | + `√`, `x²`, `xʸ`, `1/x`, `log`, `π`, `e` |
| **Финансовый** | + `+%`, `-%` (прибавить/убавить процент от левого числа) |
| **Программирование** | + `AND`, `OR`, `XOR`, `NOT`, `«`, `»`, `MOD` |

Переключение — через меню **Режим**, или вручную в `config.py` (все раскладки вынесены в константы).

## ⌨️ Горячие клавиши

| Клавиша | Действие |
|---|---|
| `0`–`9` | цифры |
| `.` / `,` | десятичная точка |
| `+` `-` `*` `/` | операторы (`-` → `−`, `*` → `×`, `/` → `÷`) |
| `^` | возведение в степень (`xʸ`, расширенный режим) |
| `%` | процент |
| `Enter` / `KP_Enter` | равно |
| `BackSpace` | удалить символ |
| `Esc` / `Delete` | очистить |
| `Ctrl+L` | очистить |
| `Ctrl+H` | открыть историю |
| `Ctrl+Q` | выход |

## 🚀 Установка

### Требования

- Python 3.10+
- Linux / macOS / Windows

### Шаги

```bash
git clone https://github.com/Pablo-aura42/igor.git
cd igor

python -m venv .venv
source .venv/bin/activate        # Linux / macOS
# .venv\Scripts\activate         # Windows

pip install -r requirements.txt
python main.py
```

## 📁 Структура проекта

```
igor/
├── main.py                  # точка входа
├── config.py                # константы, раскладки, режимы
├── requirements.txt
├── core/
│   ├── calculator.py        # движок вычислений (без Tkinter)
│   ├── settings.py          # сохранение/загрузка конфига
│   └── themes.py            # 12 цветовых тем + ThemeManager
└── ui/
    ├── app.py               # главное окно: связывает всё вместе
    ├── display.py           # виджет дисплея
    ├── button_panel.py      # сетка кнопок (пересобирается по режимам)
    ├── menu_bar.py          # кастомная панель меню в цветах темы
    ├── history_dialog.py    # окно истории
    └── about_dialog.py      # окно «О программе»
```

**Принцип:** `core/` ничего не знает про Tkinter, `ui/` ничего не знает про математику. Их связывает `app.py`. Так логику можно тестировать отдельно, а интерфейс — менять, не боясь сломать вычисления.

## 💾 Конфигурация

Все настройки хранятся в:

```
~/.config/igor/config.json
```

Там лежат:

- текущая тема (`theme`)
- текущий режим (`mode`)
- история вычислений (`history`, до 50 записей по умолчанию)

Удалить конфиг можно через **Справка → О программе → Удалить конфиг** или вручную:

```bash
rm ~/.config/igor/config.json
```
